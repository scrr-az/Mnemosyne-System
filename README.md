# The Mnemosyne Sistem

## Technical Information

The Mnemosyne System is a website built on React and Typescript, with CSS. Three.js is used to display 3D objects.

## Run Locally

These are the steps to run a local version of the product (for production).

### First Time

1. Check if Node.js is installed in your computer (with ```node -v```) and, if not, install it [from their website](https://nodejs.org/en/download).
2. Download/Clone the repository.
3. Open a terminal inside the project folder.
4. Install the dependencies by running ```npm install```.
5. Start the development server by running ```npm run dev```.
6. Open the local version with the link in the terminal.


### Already Opened It Before

You only need to do steps 5 and 6 to run it locally again.
